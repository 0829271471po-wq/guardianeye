# GuardianEye 👁️ — ระบบกล้องอัจฉริยะตรวจจับการล้มและจดจำใบหน้าสำหรับผู้สูงอายุ

กล้องราคาประมาณ 300 บาท (ESP32-CAM) ติดในบ้าน ระบบจะ **ตรวจจับการล้มอัตโนมัติ** รู้ว่า **ใครล้ม** และ **แจ้งเตือนลูกหลานทาง Telegram พร้อมรูปภาพ** ทันที

## ที่มาของปัญหา
ประเทศไทยเข้าสู่สังคมผู้สูงอายุ ผู้สูงอายุจำนวนมากอยู่บ้านคนเดียวช่วงกลางวัน การล้มเป็นอุบัติเหตุที่อันตราย ถ้าไม่มีใครเห็นและช่วยเหลือทันที อาการอาจรุนแรงขึ้นมาก

## ความสามารถ
| ฟีเจอร์ | รายละเอียด |
|---|---|
| ตรวจจับการล้ม | วิเคราะห์ท่าทางร่างกายด้วย AI (MediaPipe Pose) + State Machine กันเตือนผิด |
| จดจำใบหน้า | รู้ว่าเป็นคนในบ้านคนไหน หรือเป็นคนแปลกหน้า (OpenCV YuNet + SFace) |
| แจ้งเตือน | ส่งข้อความพร้อมรูปเข้า Telegram เช่น "⚠️ ตรวจพบ คุณยาย ล้มที่ห้องนั่งเล่น!" |
| แจ้งคนแปลกหน้า | เห็นต่อเนื่อง ≥ 3 วินาทีจึงแจ้ง และมี cooldown กันส่งรัว |
| บันทึกเหตุการณ์ | `logs/events.csv` และรูปใน `snapshots/` |
| หน้าจอแสดงผล | ภาพสด + โครงร่างกาย + กรอบใบหน้า + ชื่อ + สถานะ + FPS |

## สถาปัตยกรรม
```
┌──────────────────┐   WiFi (HTTP MJPEG)   ┌──────────────────────────────────┐
│ ESP32-CAM ("ตา")  │ ────────────────────> │ คอมพิวเตอร์ Python ("สมอง")          │
│ ส่งภาพสดอย่างเดียว  │                       │ camera.py         อ่านภาพ (thread)  │
└──────────────────┘                       │ fall_detector.py  ตรวจล้ม            │
                                           │ face_recognizer.py จดจำใบหน้า        │
                                           │ notifier.py       ส่ง Telegram       │
                                           │ event_logger.py   บันทึกเหตุการณ์      │
                                           └────────────────┬─────────────────┘
                                                            │ Internet (เฉพาะตอนเกิดเหตุ)
                                                            ▼
                                                 📱 Telegram ของลูกหลาน
```
**ทำไมประมวลผลบนคอม ไม่ใช่บนกล้อง?** ESP32-CAM มี RAM น้อย รัน AI ตรวจท่าทางไม่ไหว จึงให้กล้องส่งภาพอย่างเดียว แล้วให้คอมที่แรงกว่าเป็นตัวประมวลผล (Edge camera + Local server)

**ความเป็นส่วนตัว:** ประมวลผลในบ้านทั้งหมด ไม่ส่งภาพขึ้นคลาวด์ ส่งรูปออกไปเฉพาะตอนเกิดเหตุเท่านั้น

## หลักการตรวจจับการล้ม
ทุกเฟรมคำนวณ 3 ค่าจากจุดไหล่ (11, 12) และสะโพก (23, 24):
1. **มุมลำตัว** — มุมของเส้นสะโพก→ไหล่ เทียบแนวตั้ง (ยืน ≈ 0°, นอน ≈ 90°)
2. **ความเร็วการตกของสะโพก** — สะโพกตกลงกี่ส่วนของความสูงภาพในช่วง 0.5 วินาที
3. **อัตราส่วนกรอบร่างกาย** — กว้าง/สูง > 1 แปลว่าตัวอยู่ในแนวนอน

```
NORMAL ──(สะโพกตกเร็ว แล้วตัวอยู่แนวนอน)──> FALL_SUSPECTED
FALL_SUSPECTED ──(ลุกขึ้นได้ก่อนครบเวลา)──> NORMAL          ← แค่ก้มเก็บของ
FALL_SUSPECTED ──(นอนอยู่ครบ 10 วินาที)──> FALL_CONFIRMED  → 📱 แจ้งเตือน
FALL_CONFIRMED ──(ลุกขึ้นแล้ว)──> NORMAL                     (cooldown 60 วิ)
```
- **นั่งลงเก้าอี้** → สะโพกตก แต่ลำตัวยังตั้งตรง → ไม่เตือน
- **นอนลงโซฟาช้า ๆ** → ตัวอยู่แนวนอน แต่ไม่ได้ตกเร็ว → ไม่เตือน
- **ล้มจริง** → ตกเร็ว + นอนราบ + ไม่ลุกขึ้นใน 10 วินาที → เตือน

ทุกค่าปรับได้ใน `config.py`

## หลักการระบุว่า "ใครล้ม" (รองรับหลายคนในภาพ)
1. MediaPipe หาโครงร่างได้พร้อมกันสูงสุด 3 คน (`MAX_PEOPLE`)
2. `person_tracker.py` จับคู่โครงร่างกับ "คนเดิม" จากเฟรมก่อนด้วยระยะจุดกึ่งกลางตัว → แต่ละคนได้หมายเลข (#1, #2) และมี State Machine การล้ม **แยกของตัวเอง**
3. ตอนจดจำใบหน้าได้ ระบบดูว่า **จมูกของโครงร่างไหนอยู่ในกรอบใบหน้า** → ติดชื่อให้ร่างนั้น ชื่อติดตัวไปตลอดแม้ตอนล้มหน้าจะไม่หันเข้ากล้อง
4. คนไหนล้ม → ใช้ชื่อที่ติดตัวคนนั้นใส่ในข้อความ Telegram (ถ้ายังไม่เคยเห็นหน้า และมีคนเดียวในภาพ → ใช้ชื่อล่าสุดที่จำได้แทน)

```
ยาย(#1) ยืน  ──┐                      Telegram: "ตรวจพบ คุณยาย ล้มที่ห้องนั่งเล่น!"
ตา (#2) ยืน  ──┼─> ยาย ล้ม → #1 FALL_CONFIRMED ─┘     (ตา #2 ยัง NORMAL ไม่ถูกเตือน)
```

## การติดตั้ง

### 1. ติดตั้ง Python 3.11
- **Windows:** ดาวน์โหลดจาก https://www.python.org/downloads/release/python-3119/ (Windows installer 64-bit) ตอนติดตั้ง **ติ๊กช่อง "Add python.exe to PATH"**
- **Mac:** `brew install python@3.11` หรือดาวน์โหลดจากลิงก์เดียวกัน

### 2. สร้าง virtual environment และติดตั้งไลบรารี
เปิด Terminal ในโฟลเดอร์ `guardianeye`

**Windows (PowerShell):**
```powershell
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
> ถ้า Activate ไม่ได้เพราะติด Execution Policy ให้รัน `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` ก่อน 1 ครั้ง

**Mac:**
```bash
python3.11 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. ดาวน์โหลดโมเดล AI
```
python download_models.py
```

### 4. ตั้งค่า Telegram Bot
1. ใน Telegram คุยกับ **@BotFather** → พิมพ์ `/newbot` → ตั้งชื่อ → จะได้ **Token**
2. ส่งข้อความอะไรก็ได้หาบอทของเรา 1 ครั้ง
3. เปิดเบราว์เซอร์ไปที่ `https://api.telegram.org/bot<TOKEN>/getUpdates` → หา `"chat":{"id": ...}` นั่นคือ **chat_id**
4. แก้ไฟล์ `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-xxxx
   TELEGRAM_CHAT_ID=987654321
   ```
   ⚠️ ไฟล์ `.env` อยู่ใน `.gitignore` แล้ว ห้ามอัปโหลดขึ้น GitHub

## วิธีใช้ / ทดสอบทีละขั้น
ทุกไฟล์รันทดสอบแยกได้ กด `q` เพื่อออกจากหน้าต่าง

| ขั้น | คำสั่ง | สิ่งที่ควรเห็น |
|---|---|---|
| 1. กล้อง | `python camera.py` | ภาพสดจาก webcam + FPS |
| 2. โครงร่างกาย + state machine | `python fall_detector.py` | เส้นโครงร่าง, มุมลำตัว, สถานะ ลองยืน/นั่ง/นอน แล้วดูค่ามุม |
| 3. Telegram | `python notifier.py` | มือถือได้ข้อความ "✅ ทดสอบการแจ้งเตือนสำเร็จ" |
| 4. ลงทะเบียนใบหน้า | `python register_face.py grandma` | กด SPACE ถ่าย 5–10 รูปหลายมุม |
| 5. จดจำใบหน้า | `python face_recognizer.py` | กรอบเขียว + ชื่อ (คนในบ้าน) / กรอบแดง unknown |
| 6. ระบบเต็ม | `python main.py` | ทุกอย่างรวมกัน + แจ้งเตือนจริง |

**ชื่อคน:** ตั้งชื่อโฟลเดอร์เป็นภาษาอังกฤษ (OpenCV วาดตัวอักษรไทยบนจอไม่ได้) แล้วจับคู่ชื่อไทยใน `config.py`:
```python
PERSON_DISPLAY_NAMES = {"grandma": "คุณยาย", "grandpa": "คุณตา"}
```

### เปลี่ยนแหล่งภาพ (แก้บรรทัด `CAMERA_SOURCE=` ในไฟล์ `.env` ที่เดียว ไม่ต้องแก้โค้ด)
| แหล่งภาพ | บรรทัดใน `.env` |
|---|---|
| Webcam ของคอม | `CAMERA_SOURCE=0` |
| ESP32-CAM | `CAMERA_SOURCE=http://<IP ESP32>:81/stream` |
| iPhone (แอป DroidCam) | `CAMERA_SOURCE=http://<IP มือถือ>:4747/video` |
| มือถือ Android (แอป IP Webcam) | `CAMERA_SOURCE=http://<IP มือถือ>:8080/video` |

- ไม่ต้องใส่เครื่องหมายคำพูด และถ้าไม่ใส่บรรทัดนี้เลย ระบบจะใช้ webcam (`0`)
- **ภาพหลุดไม่ต้องปิดโปรแกรม:** ถ้า Wi-Fi สะดุดหรือกล้องรีบูต จอจะขึ้น "Camera disconnected - reconnecting..." แล้วระบบเชื่อมต่อใหม่เองทุก 3 วินาที (`RECONNECT_DELAY`) ถ้ากล้องไม่ส่งภาพเกิน 5 วินาที (`STREAM_TIMEOUT`) จะถือว่าหลุด ปรับทั้งสองค่าได้ใน `config.py`
- **ESP32-CAM ตั้งความชัดให้อัตโนมัติ:** ทุกครั้งที่เชื่อมต่อ โปรแกรมจะส่งค่า `ESP32_SETTINGS` ใน `config.py` (ค่าเริ่มต้น 800x600, quality 20 ≈ 10–14 ภาพ/วินาที) ไปตั้งให้กล้อง เพราะกล้องลืมค่าทุกครั้งที่ไฟดับ — อยากลื่นขึ้นให้ลด `framesize` อยากคมขึ้นให้ลด `quality`
- ESP32-CAM ส่งภาพได้ทีละ 1 โปรแกรม ถ้าเปิดหน้า stream ในเบราว์เซอร์ค้างไว้ ให้ปิดก่อนรัน Python

### ตั้งค่า ESP32-CAM (ไม่ต้องเขียนโค้ดเอง)
1. Arduino IDE → Boards Manager → ติดตั้ง **esp32 by Espressif**
2. เลือกบอร์ด **AI Thinker ESP32-CAM**
3. เปิด `File > Examples > ESP32 > Camera > CameraWebServer`
4. ในไฟล์ตั้งค่า เปิดบรรทัด `#define CAMERA_MODEL_AI_THINKER` (ปิดรุ่นอื่น) และใส่ชื่อ/รหัส WiFi (ต้องเป็น 2.4 GHz)
5. อัปโหลดผ่านบอร์ด ESP32-CAM-MB → เปิด Serial Monitor (115200) จะเห็นเลข IP
6. เปิด `http://<IP>` ในเบราว์เซอร์ ตั้ง Resolution เป็น **VGA (640x480)**
7. ใส่ลิงก์ใน `.env` เช่น `CAMERA_SOURCE=http://192.168.1.60:81/stream` (เปลี่ยนเป็น IP จริงจาก Serial Monitor) แล้วทดสอบด้วย `python camera.py`
   - แนะนำให้ล็อก IP ของ ESP32-CAM ไว้ในเราเตอร์ (DHCP reservation) ไม่งั้นเปิดเครื่องใหม่ IP อาจเปลี่ยน ต้องมาแก้ `.env` ใหม่

```
├── person_tracker.py    # ติดตามหลายคน + ผูกใบหน้ากับร่างกาย (รู้ว่าใครล้ม)

├── models/              # ไฟล์โมเดล (.onnx, .task)
├── known_faces/<ชื่อ>/   # รูปใบหน้าคนในบ้าน
├── snapshots/           # รูปตอนเกิดเหตุ
├── logs/events.csv      # ประวัติเหตุการณ์
├── requirements.txt
├── .env                 # Token Telegram + ลิงก์กล้อง CAMERA_SOURCE (ห้าม commit)
└── .env.example         # ตัวอย่างไฟล์ .env
```

## ข้อจำกัดและแนวทางพัฒนาต่อ
- ESP32-CAM มองในที่มืดไม่ได้ → ต่อยอดใช้กล้องอินฟราเรด
- กล้องตัวเดียวมีจุดอับ/ถูกสิ่งของบัง → ใช้หลายกล้องหลายห้อง
- รองรับได้หลายคน แต่ถ้าคนเดินซ้อนทับกัน/สวนกันใกล้ ๆ หมายเลขอาจสลับกันได้ (ต่อยอด: ใช้ tracker ที่ดูลักษณะภายนอกด้วย เช่น DeepSORT)
- ใบหน้าต้องหันเข้ากล้องอย่างน้อยครั้งหนึ่งก่อนล้ม ระบบถึงจะรู้ชื่อคนนั้น
- ถ้าโครงร่างกายหายจากภาพนานเกิน 3 วินาทีตอนกำลังสงสัยว่าล้ม ระบบจะยกเลิกการสงสัย
- ต่อยอด: ปุ่ม "ฉันไม่เป็นไร" ยกเลิกการเตือน, ลำโพงถาม "เป็นอะไรไหม", เว็บ dashboard ดูประวัติ, แจ้งเตือนหลายช่องทาง

## โค้ดกล้อง ESP32-CAM

อยู่ใน `firmware/CameraWebServer/` (ดัดแปลงจากตัวอย่าง CameraWebServer ของ Espressif) ก่อนอัปโหลดลงบอร์ด ให้แก้ `YOUR_WIFI_NAME` กับ `YOUR_WIFI_PASSWORD` เป็นชื่อและรหัส Wi-Fi ของบ้าน (ต้องเป็น 2.4 GHz)
